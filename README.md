About the Project

The Inventory Management System is a simple command-line based Python project developed to manage product and stock information.

The system allows the user to add, view, search, update, and delete products. It also provides options for purchasing and selling stock, checking low-stock products, and generating an inventory report.

The project is completely local and does not require a database, internet connection, GUl, or any external service.

Features

• Add new products

Display all products

Search for a product

Update product details

Delete products

Purchase and update stock

Sell products

Check low-stock products

Generate inventory report

Save inventory data locally

Load previously saved data

Basic input validation

Technologies Used

• Python

• JSON file handling

• Command Line Interface
